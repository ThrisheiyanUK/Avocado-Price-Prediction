# 🤖 Model Setup Instructions

## 📋 Required Model Files

The following files are required to run the application but are too large for GitHub:

- `random_forest_model.pkl` (382MB)
- `region_encoder.pkl`

## 🚀 How to Generate Model Files

1. **Run the model training script:**
   ```bash
   python model.py
   ```

2. **This will create the required files:**
   - `random_forest_model.pkl` - The trained Random Forest model
   - `region_encoder.pkl` - The region label encoder

## ⚡ Quick Setup

```bash
# Clone the repository
git clone https://github.com/ThrisheiyanUK/Avocado-Price-Prediction.git
cd Avocado-Price-Prediction

# Install dependencies
pip install flask pandas numpy scikit-learn joblib

# Train the model (this creates the .pkl files)
python model.py

# Run the application
python app.py
```
